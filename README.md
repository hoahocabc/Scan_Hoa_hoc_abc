# ScanhoahocABC (v57.0 — Hướng Dẫn Sử Dụng Nhanh)

## Các nâng cấp chính trên bản v57.0
1. **Nâng cấp thuật toán 📏 Căn thẳng dòng (đổi tên gọn, nắn thẳng rõ rệt)**:
   - Mở **🛠 Sửa → ☰** và bấm **📏 Căn thẳng dòng** khi trang sách hoặc vở kẻ bị cong/nghiêng.
   - Nhận diện chuẩn cả đường kẻ ngang mảnh 1–2px, chữ nghiêng lẫn trang sách dày có dòng trên cong lên / dòng dưới cong xuống để nắn thẳng hàng mượt mà.
2. **Bắt rìa ổn định & chính xác (kể cả giấy trắng trên nền trắng)**:
   - Khung camera đứng vững chống nhảy 3 nhịp, giữ thẳng tuyệt đối mặc định cho trang phẳng.
3. **Tách nền (`🪄 Tách nền`) sạch hoàn toàn chữ mặt sau giấy mỏng & Ảnh gốc độ nét cao**:
   - Mặc định hiển thị **🖼 Ảnh gốc** độ nét cao (`🔍 Độ nét 65%`), tách nền xóa sạch chữ hằn mặt sau về trong suốt.
4. **Chạy Offline**:
   - Trên Windows: giải nén và mở `Chay_DocScan_Offline.bat` (hoặc `index.html`).
   - Trên GitHub Pages / điện thoại: tải đủ 5 tệp lên kho lưu trữ và mở bằng trình duyệt.
